# Sudoku Solver (TDD Based)

### 🎯 Objective
A high-performance Sudoku engine utilizing a **Recursive Backtracking Algorithm** to solve any valid 9x9 grid.

### 🛠 Tech Stack
- JavaScript (ES6)
- Chai & Mocha (for Test-Driven Development)

### 🚀 Key Features
- **Algorithm:** Efficient backtracking logic with validation checks.
- **Extensive QA:** Includes 12 unit tests for solver logic and 8 functional tests for API endpoints.
- **Grid Validation:** Instant error detection for invalid row/column/region placements.
